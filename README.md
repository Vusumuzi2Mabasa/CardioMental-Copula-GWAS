# Joint genetic association with covariate dependent phenotype dependence

**Vusumuzi Mabasa**

This fully synthetic methodological study evaluates common-SNP association tests for a continuous cardiometabolic-like outcome and binary mental-health-like outcome. It contains no patient data, clinical discoveries, AWI-Gen data or Genomic SEM analysis.

The version-controlled protocol in `protocol/design.json` specifies calibration and fresh evaluation streams before the main simulation. Numerical controls and an independent base-R likelihood implementation precede the benchmark. The research manuscript and results will be generated after the prespecified simulation and audit complete. This is not a claim that copula GWAS or covariate-dependent copula regression is new.
