2. WHAT IS TESTED

Joint association: at least one phenotype is associated with a marker.
Conjunction: both phenotypes have marginal association with the same marker.
Colocalisation: one causal variant versus distinct causal variants in the tested
candidate region, under a single-causal-variant model and declared priors.
Neither a copula dependence parameter nor a conjunction rejection establishes a
shared causal variant. Colocalisation does not establish a causal effect of one
disease on another. No real patient or AWI-Gen data are analysed.

Total: 31,200 datasets, 3,200 generated participants per dataset.
Seeds: reference split 29103100, calibration 29103101, evaluation 29103102,

Phenotypes are continuous pressure and binary depression proxies. Equations,

7. INFERENCE AND CALIBRATION

Per-SNP OLS and logistic MLE adjust for intercept, age, sex, measured exposure,
and squared age. Sandwich HC0 variances and cross-trait influence covariance
support marginal and omnibus Wald tests. Bonferroni correction covers 64 markers.
The conjunction p-value is max(p_C,p_M). It identifies two associations at a tag,
not necessarily one directly shared causal effect.

Primary coloc ABFs use non-overlapping participant halves. Quantitative prior SD
0.15 in fitted outcome units, logistic prior SD 0.20 log OR, p1=p2=1e-4,
p12=1e-5, with p12 sensitivity 1e-6 and 1e-4. Model-based variances enter the
standard ABFs. A whole-sample overlap diagnostic changes both N and error dependence.
H0 neither, H1 cardio only, H2 mental only, H3 distinct causes, H4 one shared cause.
PP4 >0.8 is compared with strict composite-null calibrated cutoffs.
The latter take the largest 191st ascending PP4 across the five 200-replicate
no-sharing banks in each stratum. Calibration does not validate genome-wide tails.

The first 20 evaluation replicates in every cell/architecture form 1,920 fixed
copula diagnostics using the unchanged original Gaussian/probit engine. Their
nominal fixed-anchor tests have a different search burden from regional tests.
They are not presented as a ranking of shared-causal-variant methods.
Main failures remain non-discoveries; calibration failures block cutoffs.

9. LEVEL TWO MULTI-SIGNAL FINE MAPPING

Frozen design/source commit: 85b0bc4.
Use the first 20 replicates of every original local calibration/evaluation cell.
This reuses 1,200 calibration and 1,920 evaluation datasets, not new cohorts.
Matched-reference and in-sample LD yield 6,240 analysis records and two SuSiE fits
per record. The source ensures ALT-allele order, signed LD and matching SNP names.
The external LD uses the 40 matched reference donors' actual paired genotypes.
In-sample continuous LD is covariate-residualised; binary LD is null-information
weighted. Both use R_used = .95R + .05I, prespecified before main fitting.

Run sequentially from the repository root:
  python v4/src/freeze.py
  python v4/src/export_finemap.py --phase cal
  Rscript --vanilla v4/src/finemap.R v4 cal
  python v4/src/finemap_summary.py --freeze
  python v4/src/export_finemap.py --phase eval
  Rscript --vanilla v4/src/finemap.R v4 eval
  python v4/src/finemap_summary.py
  Rscript --vanilla v4/src/check_finemap.R v4

SuSiE uses L=5, 95% credible sets, default purity checks, at most 1,000 iterations,
and no residual-variance estimation. The binary summary likelihood is approximate.
No credible set is a valid no-discovery; nonconvergence is retained as a failure.
coloc.susie evaluates retained signal pairs. Maximum pairwise PP4 >.8 is a
conventional decision score, not a global posterior for at least one sharing event.
Calibration takes the maximum across five no-sharing banks, with strict rejection.
For each 20-replicate bank the averaged rank bound is 1/21, not conditional error
control for a realised bank. Any calibration failure disables that calibrated arm.
PIP and credible-set outputs are retained, including causal recovery and set sizes.
The matched single-causal comparison uses the identical 20-replicate subset/banks.
The small panel supports a secondary methodological comparison, not universal
superiority claims or real clinical fine-mapping conclusions.

10. LEVEL THREE GENETIC COVARIANCE AND CORRELATION

The separate model generates a synthetic polygenic genome from 22 independent
blocks of 32 common variants each. The LD templates are real chromosome 22 windows
at 20.0,21.0,...,41.0 Mb, each 100 kb long. They are NOT real chromosome 1-22 data.
Source positions and population-specific haplotypes are retained in v4/reference.
It is a 704-marker synthetic genome-scale benchmark, not a complete African
whole-genome reference. This scope is explicit in the README and Word report.

The committed derived haplotypes are sufficient to reproduce the simulations.
To independently reconstruct all templates and cached kernels in a separate copy:
  python v4/src/kernel.py --raw /path/to/checksum-verified/Phase3/files

The model uses n=600/1200, YRI/LWK, genetic variances .4/.4, residual variances
.6/.6, genetic correlations -.5/0/.5 and residual correlations 0/.4. Simulated
genotypes define a unit-diagonal relationship kernel. Both genetic and residual
covariances are estimated, so environmental dependence is not assumed to be genetic.
Covariates are projected out before the kernel eigendecomposition. The exact
bivariate restricted likelihood is solved with analytic gradients. An independent
R optimiser and dense-matrix likelihood checks validate calculations.

The continuous-liability benchmark is exact for this mixed model. The observed
depression proxy is binary, population prevalence .15, sensitivity .90, specificity
.98; its Gaussian working REML fit is explicitly approximate. Information-based
interval coverage, bias, RMSE, boundaries and empirical error rates are evaluated.
There is no clinical ascertainment. Genetic correlation approximately cancels
liability/diagnostic scale factors; covariance transformations are separately
labelled approximations. Positive/negative effects can cancel genome-wide genetic
covariance even when many variants affect both traits. No Genomic SEM is used.

Initial experiment, preserved:
  python v4/src/test_reml.py
  python v4/src/polygenic.py
  python v4/src/polygenic_summary.py

The initial run contains 1,600 calibration plus 2,400 evaluation cohorts.
Small-bank cell-level uncertainty motivated a uniform prospective amplification,
frozen in commit dd84837. The model and all generating parameters remained fixed.
Initial results remain published; the amplification uses entirely fresh seeds.

Confirmatory larger-bank validation:
  python v4/src/polygenic_validation.py
  python v4/src/polygenic_summary.py --validation
  Rscript --vanilla v4/src/check_reml.R v4

It adds 8,000 calibration and 4,800 fresh evaluation cohorts. There are 1,000 null
calibration cohorts per population/sample-size/residual-correlation stratum, and
200 evaluation cohorts for each genetic correlation in each stratum. Strict
rank-951 thresholds are frozen before fresh evaluation. Seed replicate offsets
1,000,000 and 2,000,000 never overlap the initial experiment. Both liability and
binary outcomes come from the same cohort and must not be double-counted.
Parameter summaries and test rates remain separate from local shared-SNP inference.
Four hundred paired bootstrap draws include calibration and evaluation uncertainty.
